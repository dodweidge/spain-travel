### 从网页重新生成导入文件

在仓库根目录运行：

```sh
python tools/export_mymaps.py --pending-only --output assets/mymaps/待同步景点 --title '待同步景点'
```

脚本读取 `index.html` 内的景点介绍、分类和参考坐标，校验标识与经纬度后同时输出 KML、CSV；它不会自行修改 Google 地图或把景点标记为已同步。目前没有待同步景点，`--pending-only` 会提示无数据且不写文件。未来导入前，应先与实际地图核对，实际导入成功后才更新网页的 `googleImported` 状态。

完整备份与各城市 KML 可一并更新：

```sh
python tools/export_mymaps.py --output assets/mymaps/西班牙与葡萄牙全部景点 --per-city
```

## 首次创建另一张地图

1. 用你的 Google 账号打开 https://www.google.com/maps/d/ 并创建新地图。
2. 点击图层里的“导入”，选择同目录的“西班牙与葡萄牙全部景点.kml”。它包含当前 23 座城市、138 处推荐景点，带中文名称、介绍和参考坐标。完整文件用于新地图，不应再追加到当前已有 138 处景点的地图。
3. 地图命名为“西班牙城市与推荐景点”。为嵌入网页，将地图设为公开可查看；保留只有你可编辑。文件不包含个人日期、航班、住宿等信息。
4. 复制该地图的分享链接，在旅游网页的“谷歌景点地图”设置中粘贴并连接。也可把链接发给我，由我直接写入 HTML。

如只需要单个城市，也提供了每座城市的 KML。导入 CSV 备用文件时选择纬度和经度定位，名称作为标题。

Google 官方说明：[导入地图项](https://support.google.com/mymaps/answer/3024836?hl=zh-Hans)、[分享与嵌入地图](https://support.google.com/mymaps/answer/3109452?hl=zh-Hans)。
